# 辅导员工作台 · iPhone 第一版

这是供 iPhone Safari 添加到主屏幕的单机版应用。当前只制作了手机界面，没有制作 Windows 桌面版，也没有自动同步。

## 已实现

- 学生档案：学号、姓名、性别、民族、班级、专业、宿舍、本人电话、家长电话、家庭住址、证件照、身份证号和出生日期；可增加自定义字段。
- 成绩：按可设置的本学期挂科门数预警；累计挂科按曾经挂科的不同课程统计，补考或重修通过后保留历史并显示状态。
- 资助：困难等级、家庭情况、资助项目、日期与金额。
- 谈话和家校联系：日期、对象、摘要、后续待办、到期日期和多张截图。
- Excel：下载四表空白模板、预览导入、导出当前数据。学生空白模板列顺序为“序号、专业、班级、学号、姓名、性别、民族、身份证号、宿舍、本人电话、家长电话、家庭住址”；除学号外均可留空。学号和身份证号列按文本设置，避免前导零丢失。
- 证件照：按学号命名的 JPG/PNG/WebP 文件打包成 ZIP，分批导入；导入前预览匹配结果。
- 本机加密：档案与附件用 6 位数字解锁密码加密保存在浏览器的 IndexedDB 中；离开超过五分钟后重新解锁。
- 传输包：导出或导入加密 ZIP。命名格式为 `辅导员工作台_数据包_v1.0.2_YYYYMMDD_HHMMSS.zip`。密码错误或文件损坏会拒绝导入。

## 使用方式

1. 把整个目录放到支持 HTTPS 的静态网站。应用代码可以托管，学生数据与附件只保存在 iPhone 本机。通过 Safari 打开网址，然后在分享菜单选择“添加到主屏幕”。
2. 首次打开时设置 6 位数字解锁密码。忘记该密码无法解密本机数据。
3. 可先导入 `演示数据_虚构.xlsx` 熟悉界面；正式使用时下载空白模板填写。请勿把真实学生资料上传到不受控的测试站点。
4. 定期在“数据”页面生成加密 ZIP，并将其保存到你管理的安全位置。ZIP 密码可以与解锁密码不同。

## 文件规则

- Excel 中所有数据表都用“学号”关联学生。成绩、资助与工作记录表的“记录ID”可以留空；导出后会自动生成，后续修改再导入时应保留。
- 学生表之外的自定义列会原样保留在学生档案和下次导出中。
- 证件照 ZIP 内的文件名为 `学号.jpg`、`学号.jpeg`、`学号.png` 或 `学号.webp`。建议每包不超过 50 MB，可分多包导入。
- 附件在导出数据包中保留；普通 Excel 导出不包含图片。图片的可读文件名使用“班级_姓名_类型_日期_序号”。

## 当前边界

- iPhone 和未来的 Windows 版之间没有自动同步。数据包为后续手动传输预留了稳定的记录标识。
- 当前没有多人账号或共享功能，也没有心理信息模块。
- 部署到 HTTPS 站点和在真实 iPhone 上验证安装、分享及大批量照片导入仍需完成，现阶段不要把它当作已经上线的正式服务。

## 本地开发与验证

在本目录运行 `python -m http.server 8765`，用电脑浏览器打开 `http://localhost:8765` 可检查界面和功能。此地址不能直接用于 iPhone 安装。

`npm.cmd test` 运行数据规则与加密包测试；`make_icon.py` 用于重新生成应用图标。网页运行时只使用目录内的资源，没有外部 JS 依赖。
